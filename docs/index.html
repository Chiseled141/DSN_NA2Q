Scale difference: NA²Q reports normalized per-episode rewards (0-100 scale), reflecting instantaneous agent performance. HiT-MAC tracks the cumulative reward over 100 simulation steps, resulting in higher aggregate values (~3000+). Both metrics effectively demonstrate learning convergence, with trends being the key performance indicator rather than absolute scale comparison.

Training Note

NA²Q - Well Optimized

NA²Q has been trained for 30,000 episodes with optimized hyperparameters. The attention mechanism enables efficient credit assignment and demonstrates strong convergence in cooperative sensor coordination tasks.

HiT-MAC - Parameters Not Fine-Tuned

HiT-MAC was also trained for 30,000 episodes, but the results remain poor because the hyperparameters have not been fine-tuned. Default parameters were used throughout training, leading to suboptimal performance compared to NA²Q.

Note: HiT-MAC's poor performance is due to untuned hyperparameters, not the algorithm itself. A properly fine-tuned training run is needed for a fair comparison.
